# Kalyani Bedre Portfolio — JavaScript Version

This version uses:

- React
- JavaScript / JSX
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

There is no TypeScript in this project.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

The Vite base is configured for:

https://kalyanib996.github.io/portfolio_kalyani/

Run:

```bash
npm run deploy
```
